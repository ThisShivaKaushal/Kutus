# Kutus
Your Slack bot is ready to chat when you send a direct message or mention it in a channel.

# Feature

It is currently available with these commands.

1. ```kutus-ping```
2. ```kutus-info```
3. ```kutus-catfact```
4. ```kutus-joke```
5. ```kutus-quote``` 
6. ```kutus-hqweather```


# Framework 


This is made using ```Javascript``` and ```nodejs```.
